=== LayoutGPT 模块化版本 ===

🎉 代码已经模块化！现在有三套程序：

=== GUI版本（最推荐）===

🖥️ 图形界面程序：layoutgpt_gui.py

python layoutgpt_gui.py

✨ 特点：
- 完整的图形界面，无需记忆命令行参数
- 包含所有原始参数：--dataset_dir, --icl_type, --K, --room, --gpt_type, --unit, --normalize, --regular_floor_plan 等
- 两个标签页：布局生成 + 可视化
- 实时日志输出
- 参数验证和错误提示
- 支持文件/目录浏览

=== 简化版本（命令行）===

1. 布局生成：run_layoutgpt_simple.py
2. 可视化：visualize_simple.py

详细说明请查看：README_modules.md

=== 快速使用 ===

# GUI版本（推荐）
python layoutgpt_gui.py

# 简化命令行版本
python run_layoutgpt_simple.py --room bedroom --K 8
python visualize_simple.py
